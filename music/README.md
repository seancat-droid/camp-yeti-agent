# Music pool

Drop `.mp3` files directly in this folder (no subfolders) -- upbeat/fun
background tracks for the text-card posts. Each post picks one at random and
loops the (silent) portrait over it for 15 seconds.

A handful of tracks (3-5) is plenty to avoid the same song on every post.
Anything royalty-free/licensed for use works -- Suno exports, royalty-free
stock tracks, etc. Add or remove tracks any time; the rotation picks up
whatever's here on the next run.
